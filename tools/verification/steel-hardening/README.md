# Immediate steel hardening evidence

These tools exercise the implemented preview. They do not qualify a design-code profile.

`browser.mjs` requires a running local web application, Microsoft Edge and an existing
Playwright-compatible module. Set `PM_TEST_URL` for the local URL (default
`http://127.0.0.1:3001`) and `PM_PLAYWRIGHT_MODULE` when Playwright is installed outside this
checkout. It imports generated KDS fibre, KDS block and EN fixtures, compares actual worker
capacities after Off/On edits, checks manual input against imported input, and captures both
themes and the signed graph at a narrow viewport. It asserts a checkbox, paired epsUk/strength
fields with native k/fuk radios, and linked percentage/direct cutoff fields without mode menus
or Advanced. Four displayed numeric fields represent three independent parameters. It checks
last-edited-basis dependency rules and saved discriminants in exported JSON. Independent line
interpolation checks worker capacities for default, direct, percentage and imported physical
cutoffs, including explicit physical-bound clearing. No project dependency is installed by the tool.
Off -> On asserts populated starter values and a nonempty curve before any manual entry; KDS
starts at 100% and EN at 90%. Incomplete data, a cutoff beyond epsUk or below yield must suppress
the invalid curve while retaining axes and diagnostic evidence. If the existing background worker
receives a deliberately invalid draft, the tool independently identifies the submitted invalid
parameters and requires a matching typed material rejection; unexpected errors still fail the run.
Axis-marker checks cover vertical dashed projections, axis-point coordinates, coincident limits,
close-label staggering and signed/Reference/Design views at normal and minimum sidebar widths.
Presentation checks additionally require zero checkbox borders at rest/hover, separation between
the strength radios, and real HTML/SVG subscript markup for engineering symbols.
Concrete and Steel must also match in rendered SVG frame/dimensions, figure spacing, curve/axis
strokes, label typography and caption style in both themes. Concrete reference captures accompany
the Steel screenshots; material-specific markers and views keep their existing checks.

Run the browser tool first, then `node --import tsx tools/verification/steel-hardening/evidence.ts`.
The latter uses the generated EN fixture for a mixed-grade preview PDF and measures grouped versus
exhaustive affine-strain extrema with identical checksums. It records preprocessing, isolated
support-check time, one end-to-end prepare/surface/report sample and peak process RSS. It does not
infer total solver speedup from an isolated loop, and small sections may have higher cache overhead.
The default artifact directory is `outputs/steel-hardening`, which is ignored by Git.

Permanent engineering oracles live in the material, geometry, analysis and report test suites:
independent endpoint interpolation/derivatives, exhaustive support and violation lists, an
independently enumerated dense strain polygon, stage-factor checks, mixed-grade Excel
recalculation, and metric/US editable-workbook round trips. Run `npm test` for the complete suite.
