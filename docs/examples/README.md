# Examples and Verification Artifacts

This directory contains engineering inputs and audit evidence, not production source code.

- `equivalent-block/`: small deterministic KDS/ACI project fixtures generated by
  `tools/fixtures/generate-equivalent-block-examples.ts` and exercised by integration tests.
- `realistic-sections/`: import-ready KDS/ACI UI examples with practical dimensions, explicit
  cover offsets, perimeter/void reinforcement cages, and solver-verified ULS loads. They are
  generated by `tools/fixtures/generate-realistic-section-examples.ts`.
- `reference-case/`: the remaining distributable P16 provenance notes, project snapshot, and
  machine-readable comparison data. Generated audit reports are not distributed.

Do not add a new peer folder named `example`, `example case`, or `samples`. New artifacts must state
their provenance, governing profile, units, expected use, and whether a generator may overwrite
them. A workbook or PDF is evidence; it is never design-code authority.
