# User Project Examples

These are import-ready copies of user-supplied project documents. Only each project and geometry
name was changed to its library name.

| Library project | Source | Contents |
| --- | --- | --- |
| `ENVICO.pm-project.json` | `Column-project (11).json` | 7 concrete regions, 1 hollow, 226 longitudinal bars, 2 load combinations |
| `Hi.pm-project.json` | `Column-project (12).json` | 3 concrete regions, 207 longitudinal bars, 1 load combination |

Both projects use profile `kds-2024-stress-strain`, method `strain-domain-surface-v1`, geometry
units mm, and actions kN/kN-m. They have no generator and must not be overwritten by the
realistic-section fixture generator.
